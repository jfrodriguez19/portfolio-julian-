# Dashboard Comercial – Power BI

![Dashboard Comercial](PORTADA.png)

## 🎯 Objetivo
Analizar ventas, rentabilidad y desempeño comercial para mejorar la toma de decisiones.

## 📁 Dataset
Datos de ventas, productos, canales y rentabilidad del negocio.  
Incluye métricas calculadas y tablas normalizadas para análisis.

## 📈 KPIs destacados
- Ventas totales
- Margen bruto
- Rentabilidad por canal
- Ticket promedio
- Variación intermensual
  
## 🔍 Insights relevantes
- El canal X tiene mayor margen pero menor volumen.
- La línea Y crece sostenidamente en los últimos 6 meses.
- El segmento Z muestra oportunidades de expansión.

## 🛠️ Herramientas
- Power BI  
- Excel  
- Modelado de datos
